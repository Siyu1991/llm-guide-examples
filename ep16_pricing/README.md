# ep16 AI 产品怎么定价

对应专栏第 16 期（辅线·商业化第 1 篇）。只依赖 numpy，不到 1 秒。所有用户和客户数据都是程序按固定种子生成的模拟数据；模型单价取 Anthropic 官方价格表（2026-10-19）的 Claude Sonnet 5.5 / Haiku 5.5，其余参数是写在代码顶部的假设值，可以直接改。

```bash
python3 pricing_sim.py     # 打印结果，并写出 outputs/ep16_results.json
python3 test_pricing.py
```

两部分：

- A. 席位制 AI 助手：1 万个席位（15% 闲置、用量重尾），比较纯席位 $20、按 token 加价 25%、席位含等额额度（池化 / 不池化）四种收法的推理毛利；再把一部分席位换成 Agent 模式（token 用量 8 倍），看不限量席位从哪里开始亏。
- B. AI 客服 Agent：2,000 家客户，比较按坐席、按 token、按结果（$0.99/次解决，含核验调用成本）的收入和毛利，算按结果收费的保本解决率，以及解决率上升时坐席收入怎样被“自我蚕食”。

每部分都有三档成本优化：不做优化、开提示缓存、缓存 + 60% 请求路由到小模型。

这里的毛利率只扣推理成本，不含托管、研发、销售和客服人力，不能直接当作公司毛利。
