# 青禾云盘 开放 API 说明

## 鉴权
调用 API 需在请求头携带 access_token。access_token 有效期 2 小时，过期后用 refresh_token 换取新的令牌，refresh_token 有效期 30 天。

## 限流
免费开发者每分钟最多 60 次请求，专业开发者每分钟最多 600 次请求。超过限流时返回 HTTP 429，响应头 Retry-After 给出需要等待的秒数。

## 错误码
- E1001：access_token 已过期，请刷新令牌。
- E1002：签名校验失败，请检查密钥与时间戳，服务器允许的时间偏差为 5 分钟。
- E2001：账户空间不足。
- E3001：文件超过单文件大小上限。
