# ep12 Agent 的可靠性与成本

对应专栏第 12 期。

- `guard.py`：权限白名单（读/写分开）、写操作人工确认、幂等键（重复请求只执行一次）、超时重试 + 指数退避、预算与步数熔断、审计日志。
- `simulate.py`：蒙特卡洛模拟"每步成功率 p、共 n 步"的任务，在裸跑 / 只重试 / 只校验 / 校验+重试四种策略下的成功率、静默出错率、转人工率和每个成功任务的成本。成本参数是假设值，写在文件开头，可以按自己业务改。

```bash
python3 simulate.py   # 纯标准库，约 0.3 秒
python3 test_guard.py
```
