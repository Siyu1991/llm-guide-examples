# ep11 多 Agent 协作

对应专栏第 11 期。同一个编码任务（写 3 个函数并通过单元测试）用三种方式完成并统计通过率、模型调用次数和上下文字符量：

1. 单 Agent，一次写完，不验证
2. 单 Agent + 程序自动跑测试、把报错喂回
3. 多 Agent：规划者 → 编码者 → 审查者（审查者也是一次模型调用）

```bash
python3 multi_agent.py      # 离线 Mock，每种配置 2000 次蒙特卡洛，约 5 秒
python3 test_multi_agent.py
```

Mock 模式下"编码者"以设定概率写出有 bug 的版本，收到报错后以 0.8 的概率修好（这是假设参数，不是模型实测）；单元测试是真的执行。设置 `OPENAI_API_KEY` 后编码者改用真实模型，每种配置跑 3 次。
