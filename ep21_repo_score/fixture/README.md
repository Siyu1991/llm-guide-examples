# DemoApp

An open-source LLM app platform example for local scoring demos.

## Quick start

Requirements:

* CPU >= 2 Core
* RAM >= 4 GiB
* Docker and Docker Compose v2.24.0 or later

```bash
cd docker
cp env.example local.env
docker compose up -d
```

Open http://localhost/install
